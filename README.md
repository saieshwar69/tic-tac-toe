# Tic-Tac-Toe 🎮

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- X and O turn switching
- Winner detection
- Draw detection
- Restart game
- Interactive game board

## Technologies Used

- HTML5
- CSS3
- JavaScript
